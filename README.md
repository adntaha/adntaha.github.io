# adntaha.github.io

Aidan Taha's personal website. Plain HTML and CSS, generated by a small build script. No framework. The only browser JavaScript is for fun: `src/board.js` (draw on the page) and `src/stars.js` (the homepage stars drawing themselves as you scroll).

```sh
npm install
npm run dev     # http://localhost:4000, rebuilds and reloads on save
npm run build   # writes the finished site to dist/
```

## Where things live

| Path | What it is |
| --- | --- |
| `content/home.yml` | Homepage words: intro, Now, Previously, margin notes |
| `content/projects/*.md` | One file per project page. `featured: 1` puts it on the homepage, `half: true` makes it a smaller entry, `thumb` is the picture pasted in the margin on `/projects/` |
| `content/archive.yml` | The quieter list of hackathon builds and small experiments on `/projects/` |
| `content/writing/*.md` | Blog posts, served at `/blog/<file-name>/` (same URLs as the old Jekyll blog) |
| `content/pages/*.md` | Standalone pages such as `/colophon/` and the 404 page |
| `site.config.js` | Name, email, links, base URL, analytics, redirects |
| `templates/` | Functions that turn content into HTML |
| `src/` | `style.css`, `board.js` (the marker/chalk tray) and `stars.js`, fingerprinted on build so they cache well |
| `public/` | Copied as-is: fonts, images, video |

## Writing

Markdown, with a few extras:

- `[^1]` footnotes
- `$x$` inline and `$$ … $$` display math (rendered at build time; no math JavaScript in the browser). Write money as `\$50`, or it may be read as math.
- `^[a note]` puts a handwritten note in the margin (a ✎ toggle on phones)
- `<!-- TODO … -->` in a body, or `# TODO …` in frontmatter or YAML, marks something unfinished. Every build lists them.

Images in `public/` get their width and height filled in automatically.

## Deploying

`.github/workflows/deploy.yml` builds and publishes to GitHub Pages on every push to `main`. A production build fails while any TODO remains, so draft copy can't go live by accident (`node build.js --allow-todos` overrides this locally). To move to a custom domain, change `url` in `site.config.js` and add a `public/CNAME` file.
